# distill-skills

Public distillations of people's public writing, laid out so a skill can be fetched over HTTPS.

Start at [ENTRY.md](./ENTRY.md). Each person lives at `skills/<slug>/`. The loader is `skills/<slug>/SKILL.md`, and it points at the raw file URLs for voice, opinions, knowledge, and boundaries.

This repository does not include source ledgers, fetched posts, or private profile notes. Quotes in the skill files are short excerpts of already-public writing, each with a source URL.
